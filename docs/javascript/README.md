# JavaScript：面试重难点的运行时解释

常用语法可以一笔带过；面试更常追问“为什么会这样”“换个执行环境还成立吗”。本模块从值、作用域、对象到异步，重点区分 ECMAScript 语言规则与浏览器/Node 宿主行为。浏览器事件循环和 Node 事件循环有各自专篇，这里只讲 Promise 等语言层机制。

| 顺序 | 主题                                    | 核心问题                                                 |
| ---- | --------------------------------------- | -------------------------------------------------------- |
| 1    | [值、相等与强制转换](values.md)         | `typeof null`、`NaN`、`==`、浮点与复制如何解释？         |
| 2    | [作用域、闭包与 this](scope.md)         | 词法环境、暂时性死区、闭包保留什么、调用时 this 怎么定？ |
| 3    | [对象、原型与 Proxy](objects.md)        | 属性查找、描述符、继承、Reflect 与代理不变量             |
| 4    | [Promise、迭代与模块](async-modules.md) | thenable 同化、错误传播、async/await、ESM 循环依赖       |
| 5    | [内存、错误与常见误区](runtime.md)      | 引用、垃圾回收、资源释放、事件循环边界                   |

补充阅读：[数组与集合](collections.md)梳理空槽、复制、Map/Set 与弱引用集合的易错语义。

面试推导优先说明前提：严格模式还是非严格模式、脚本还是模块、浏览器还是 Node、代码的调用方式。少背脱离环境的输出题。类型层约束见 [TypeScript](../typescript/README.md)。
