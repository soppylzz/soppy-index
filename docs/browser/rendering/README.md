# 浏览器渲染

[渲染流水线](./rendering.md)沿 Parse、Style、Layout、Paint、Raster 和 Composite 解释页面如何变成像素，再讨论后续修改的失效范围、同步布局与合成更新。

## 面试常考点

先说一次修改影响哪些阶段，再解释优化手段：改变宽度可能需要布局，读取几何可能迫使浏览器同步更新，transform / opacity 的更新也不能无条件保证只走合成。重排、重绘和合成是更新所需工作的差异，不是三套互不相关的流程。

脚本发现、下载与执行顺序归入[资源加载](../loading/README.md)；任务和渲染机会的关系归入[事件循环](../event-loop/README.md)。本模块集中解释渲染本身，不提供独立 demo。
