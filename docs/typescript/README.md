# TypeScript：从值到类型，再回到运行时

TypeScript 的价值是让约束在编码时可检查；编译后的 JavaScript 仍按运行时规则执行。建议边读边在编辑器中改变示例类型，观察编译器报错，再问“运行时实际会发生什么”。本模块覆盖语言、推断和工程落地；复杂题型另见 [Type Challenges](../../handwrite/type-challenges/)。

| 顺序 | 主题                            | 学习目标                                         |
| ---- | ------------------------------- | ------------------------------------------------ |
| 1    | [类型系统基础](basics.md)       | 结构化兼容、字面量、联合/交叉、any/unknown/never |
| 2    | [缩小与控制流](narrowing.md)    | 安全处理外部数据、判别联合、穷尽检查             |
| 3    | [函数、泛型与推断](generics.md) | 约束、返回类型、重载、上下文推断与方差           |
| 4    | [类型运算](type-operations.md)  | keyof、映射、条件、infer、模板字面量             |
| 5    | [对象建模](modeling.md)         | interface/type、可选/只读、类、枚举与不健全边界  |
| 6    | [工程配置与声明](tooling.md)    | tsconfig、模块、声明文件、运行时校验与迁移       |

进阶阅读：[方差与高级推断](variance.md)解释泛型可替换性，[装饰器与旧代码互操作](decorators.md)区分新旧装饰器及 namespace。

最重要的主线是：从真实运行时数据建模 → 在分支中缩小 → 用泛型保存输入输出关系 → 用类型运算表达重复约束 → 在模块边界验证不可信数据。示例中的类型运算不会在运行时生成校验器。
