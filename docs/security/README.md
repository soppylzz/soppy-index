# 前端安全：沿请求与信任边界学习

先读 [网络协议栈](../network/README.md)：安全问题常发生在从域名到连接、从 HTTP 响应到 DOM、从浏览器凭据到服务端权限判断的边界。这里按威胁发生的位置组织，避免把防护头当成孤立清单。

| 顺序 | 主题                                      | 核心问题                                        |
| ---- | ----------------------------------------- | ----------------------------------------------- |
| 1    | [威胁模型与边界](model.md)                | 攻击者能控制什么？哪些判断必须在服务端做？      |
| 2    | [跨源与浏览器边界](browser-boundaries.md) | 同源、CORS、跨窗口/iframe、WebSocket 有何限制？ |
| 3    | [XSS 与注入](xss.md)                      | 不可信文本怎样变成代码？怎样按输出位置防护？    |
| 4    | [Cookie、会话与 CSRF](session-csrf.md)    | 浏览器自动带凭据带来什么风险？                  |
| 5    | [响应头与部署](headers.md)                | CSP、HSTS、iframe 限制各解决什么？              |
| 6    | [URL、文件与供应链](engineering.md)       | 可控 URL、上传、依赖与前端秘密如何审查？        |

专题：[点击劫持与 DOM Clobbering](clickjacking-dom.md)补充 iframe 视觉攻击和 DOM 命名访问风险。

每一篇都把“攻击前提 → 发生过程 → 防护 → 防护边界”连起来。安全测试只在自己有权限的环境中开展。身份认证和授权的完整流程见 [Auth](../auth/README.md)。
