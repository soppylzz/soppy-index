# 实验验证记录

2026-10-19，在 Node 22.23.2、Next.js 16.4.0、React 19.2.0 环境执行。两个 Next.js 开发进程分别监听 127.0.0.1:3000 与 127.0.0.1:3001，检查后已停止。

## 已执行

| 检查 | 实际结果 |
| --- | --- |
| 根与工作区 typecheck（含 Security 应用） | 通过 |
| Security 应用 ESLint 与本次文件 Prettier | 通过 |
| Next.js 生产构建 | 编译、类型检查与页面生成通过；未声称生产多实例状态可靠 |
| 纯协议测试，2 组 | 拒绝错误签名、audience、token 用途、过期、错误主体类型；限制回调地址与 PKCE 方法 |
| HTTP 集成测试，5 组 | 会话、资源权限、BFF、公开客户端、服务调用和设备授权相关断言通过 |

HTTP 检查包括：未登录 401、Alice/Bob 资源隔离、错误 CSRF token、登录轮换与退出后旧 Cookie 失效；BFF 兑换及资源代理、伪造和重复回调拒绝；错误 verifier 与授权码重放拒绝；用户和服务 scope 隔离、错误客户端凭据；设备授权等待、批准、一次性消费和过快轮询。

跨源允许头、预检响应与不可信 Origin 不获允许头也已通过 HTTP 检查。这些只能证明服务器响应配置，不能证明浏览器的 CORS、SameSite 或 Cookie 存储行为。
