# 字节、编码与文件：实验走查

[知识导航与运行命令](./README.md) · [完整实现](./index.ts)

先读相应笔记并预测，再运行完整入口。下表的“应看到”是这个实验控制条件下的检查点，具体结果以当前运行输出为准。

| 问题 | 看哪里 | 应看到与原因 |
| --- | --- | --- |
| 字符长度等于传输长度吗？ | 比较“中😀” | 字符串长 3 个 UTF-16 code unit，UTF-8 编码为 7 字节。 |
| 切片会复制吗？ | 改写 `subarray` | 父 Buffer 随共享视图变化；显式 `Buffer.from` 副本保持原值。 |
| 分块解码为何会乱码？ | 把多字节字符拆成两个 chunk | 逐块 `toString` 可能产生替换字符；`StringDecoder` 保留未完成字节。 |
| 文件路径能直接拼 URL 吗？ | 读写含空格、`#`、`%` 的临时文件 | file URL 往返转换正确；关闭句柄后删除目录。 |

路径边界只做词法检查，不能防符号链接竞态；没有验证 Windows UNC、断电持久性或跨平台 watch 行为。
