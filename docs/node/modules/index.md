# 模块、包边界与原生 TypeScript：实验走查

[知识导航与运行命令](./README.md) · [完整实现](./index.ts)

先读相应笔记并预测，再运行完整入口。下表的“应看到”是这个实验控制条件下的检查点，具体结果以当前运行输出为准。

| 问题 | 看哪里 | 应看到与原因 |
| --- | --- | --- |
| 重复加载会重复求值吗？ | 比较两次 `require` 与 `import` | 同一解析身份复用 CJS 导出对象或 ESM namespace；ESM 导出绑定更新可被后续读取。 |
| CJS 能加载 ESM 吗？ | 比较同步图与含 TLA 的图 | 当前最低版本可 `require` 符合条件的同步图；含顶层 await 的图需要异步加载。 |
| 包能隐藏私有子路径吗？ | 运行 `package/probe.mjs` | 自引用、`#imports` 和 import/require 条件按包配置解析；未公开的包子路径被拒绝。 |
| 类型会在运行时检查吗？ | 直接执行 `typed.ts` | 打印 42 与 `number`；这是类型擦除后的运行结果，类型检查由 `tsc` 另做。 |

实验未覆盖循环依赖、monorepo 链接布局或完整发布流程；两套条件入口故意使用不同实现，不能当作共享单例。
