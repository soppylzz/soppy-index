# 内存与性能诊断

[Node 实验总入口](../run.ts)

看到 RSS 升高或请求变慢，下一步应该查什么？

先确定指标测量什么，再选择证据。用有界缓存理解引用保留，用短忙循环观察事件循环延迟与利用率；不要从一次数字直接推断泄漏或性能收益。

- [内存与引用](./memory.md)：堆、Buffer、RSS 与保留链。
- [运行时观测](./observability.md)：日志、延迟与利用率。
