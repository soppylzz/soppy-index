# MonoStack（单调栈）

> 栈内元素从栈底到栈顶保持单调（递增或递减）的栈；把「找下一个更大 / 更小元素」类问题的暴力 `O(n^2)` 优化到 `O(n)`

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm monoStack
```

观察下一个更大元素、每日温度与柱状图最大矩形。

## 1. 定义与性质

- 单调栈 = 普通栈 + 单调性约束：新元素入栈前，先把破坏单调性的栈顶元素依次弹出
- 核心性质：谁弹出栈顶元素，谁就是被弹元素「右侧第一个更大 / 更小元素」—— 每个元素的答案在它出栈那一刻确定
- 方向配对（最容易记反）：
  - 单调不增栈（栈底到栈顶非递增）：当前元素比栈顶大时弹出 -> 求「下一个更大元素」
  - 单调不减栈（栈底到栈顶非递减）：当前元素比栈顶小时弹出 -> 求「下一个更小元素」
- 存下标而不是值：既拿到值，又能算距离 / 宽度
- 每个元素至多入栈、出栈各一次 → 整体 `O(n)`（均摊），空间 `O(n)`

## 2. 工作过程

以 `nums = [2, 1, 2, 4, 3]` 求「右侧第一个更大元素」为例（单调不增栈存下标，表中以值示意）：

| 当前元素 | 动作            | 弹出得到的答案    | 栈     |
| -------- | --------------- | ----------------- | ------ |
| 2        | 直接入栈        | -                 | [2]    |
| 1        | 1 < 2，直接入栈 | -                 | [2, 1] |
| 2        | 弹出 1          | 1 的答案是 2      | [2, 2] |
| 4        | 弹出 2、2       | 两个 2 的答案是 4 | [4]    |
| 3        | 3 < 4，直接入栈 | -                 | [4, 3] |

遍历结束后栈内元素（4、3）右侧没有更大元素，答案记 -1。这里用严格的 `>` 弹栈，所以相等的两个 2 都留在栈内，栈底到栈顶是“非递增”，不能称作严格递减。

判断方向时直接追踪弹栈条件：寻找右侧更大元素，要让尚未等到答案的较大值留在底部；寻找右侧更小元素则相反。源码中 `nextGreater` 前的 increasing 注释与实际条件不一致，应以比较条件和这组走查为准。柱状图示例弹出较高柱子，留下的则是单调不减栈。

## 3. 核心操作

| 操作  | 时机                     | 含义                                 |
| ----- | ------------------------ | ------------------------------------ |
| push  | 当前元素不破坏单调性     | 等待自己的「下一个更大 / 更小」出现  |
| pop   | 当前元素与栈顶破坏单调性 | 被弹元素的答案就是当前元素           |
| drain | 遍历结束                 | 栈内剩余元素右侧无更大 / 更小，记 -1 |

## 4. 应用场景

| 场景 | 栈的类型 | 要点 |
| --- | --- | --- |
| 下一个更大 / 更小元素（每日温度、循环数组） | 不增 / 不减 | 存下标算距离；循环数组用 `i % n` 走两遍 |
| 柱状图中最大矩形 | 递增 | 弹出时高度确定，宽度由左右第一个更矮元素确定 |
| 接雨水 | 递减 | 弹出时按「左右挡板取矮」竖着接水 |
| 股票跨度 | 递减 | 弹出时累计跨度，支持在线查询 |
| 移除 K 个数字 / 去重使字典序最小 | 递增 | 贪心：栈顶比当前大就弹，弹出次数有限制 |
