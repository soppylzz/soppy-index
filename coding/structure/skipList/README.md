# SkipList（跳表）

> 有序链表加「多层快速通道」：查找 / 插入 / 删除期望 `O(logn)`，用随机层数代替旋转维持平衡，Redis zSet 的底层

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm skipList
```

观察有序遍历、查找、插入与删除；内部层高随机，逻辑结果仍遵循有序集合语义。

## 1. 定义与性质

- 底层是完整的有序链表；节点插入时以概率 p（常取 1/4）逐层晋升，形成越来越稀疏的上层索引
- 查找从最高层出发：能右移就右移，走不动就下一层 —— 跳过不可能的区段
- 随机化换平衡：期望层数 `O(logn)`，单次操作期望 `O(logn)`；没有旋转，实现比平衡树简单得多
- 每上一层节点数期望变为 p 倍，总空间期望 `O(n)`

## 2. 节点表示

- 节点存 score 与 forward 数组：`forward[i]` 指向同层的下一个节点
- 虚拟头节点占满最高层；实际层数 level 随插入增长、删除后回落
- 插入 / 删除前先自顶向下记录每层的前驱节点（updates 数组），后续操作都在它上面进行

## 3. 核心操作

| 操作        | 做法                              | 复杂度         |
| ----------- | --------------------------------- | -------------- |
| search      | 高层向右、走不动下沉              | 期望 `O(logn)` |
| insert      | 记录前驱 + randomLevel + 逐层插入 | 期望 `O(logn)` |
| erase       | 记录前驱 + 逐层摘除 + 回落 level  | 期望 `O(logn)` |
| randomLevel | 随机数连续小于 p 的次数 + 1       | 期望 `O(1)`    |

## 4. 应用场景

| 场景                       | 要点                                        |
| -------------------------- | ------------------------------------------- |
| Redis Sorted Set           | score 排序，ZRANGE 范围查就是底层链表走一段 |
| LSM-tree memtable          | LevelDB / RocksDB 的内存有序层              |
| 并发有序结构               | Java ConcurrentSkipListMap，锁粒度天然细    |
| 有序 + 高频插删 + 范围查询 | 替代平衡树的实用选择                        |
