# FenwickTree（树状数组）

> Binary Indexed Tree：下标按二进制最低位分块管辖区间和，「单点更新 + 前缀查询」都 `O(logn)`，代码只要十几行

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm fenwickTree
```

观察前缀和、区间和、单点更新与逆序对计数。

## 1. 定义与性质

- 定位：前缀和数组查 `O(1)` 改 `O(n)`，裸数组查 `O(n)` 改 `O(1)`；树状数组两者平衡成 `O(logn)`
- 核心思想：下标 i 的节点管辖一段长为 lowbit(i) 的区间，`tree[i] = sum(i - lowbit(i), i]`
- `lowbit(i) = i & -i`，取出 i 二进制的最低位 1（补码性质）
- 两条链，方向相反：
  - 更新向上：位置 i 变化沿 `i += lowbit(i)` 走，沿途节点都管辖 i
  - 查询向下：前缀和沿 `i -= lowbit(i)` 走，把互不重叠的管辖区间加起来
- 只能维护可逆运算（求和类）：min / max 无法用减法回退，那种场景选线段树

## 2. 管辖区间（n = 8）

| 下标 i  | lowbit(i) | 管辖区间 |
| ------- | --------- | -------- |
| 1(0001) | 1         | [1, 1]   |
| 2(0010) | 2         | [1, 2]   |
| 3(0011) | 1         | [3, 3]   |
| 4(0100) | 4         | [1, 4]   |
| 5(0101) | 1         | [5, 5]   |
| 6(0110) | 2         | [5, 6]   |
| 7(0111) | 1         | [7, 7]   |
| 8(1000) | 8         | [1, 8]   |

下标必须从 1 开始：0 的 lowbit 是 0，两条链都会死循环。

## 3. 核心操作

| 操作             | 做法                           | 复杂度    |
| ---------------- | ------------------------------ | --------- |
| update(i, delta) | i 沿 `i += lowbit(i)` 链上累加 | `O(logn)` |
| prefixSum(i)     | i 沿 `i -= lowbit(i)` 链上累加 | `O(logn)` |
| rangeSum(l, r)   | prefixSum(r) - prefixSum(l-1)  | `O(logn)` |

## 4. 应用场景

| 场景                   | 要点                                               |
| ---------------------- | -------------------------------------------------- |
| 动态前缀和 / 区间和    | 单点改 + 区间查的标准场景                          |
| 逆序对计数             | 从右往左扫，查「已出现且更小的个数」；值大先离散化 |
| 计数排名 / 值域第 k 小 | 值域建树，prefixSum 即排名，配二分找第 k 小        |
| 二维单点改 + 子矩阵查  | 每个维度一条 lowbit 链，嵌套两层循环               |
