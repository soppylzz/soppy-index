# SegTree（线段树）

> 每个节点管辖一段区间的二叉树：单点 / 区间更新、区间查询都 `O(logn)`，合并运算可换（求和 / 最值 / 计数），区间统计的万能底座

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm segTree
```

观察区间求和与 lazy propagation 的区间更新。

## 1. 定义与性质

- 每个节点管一段 `[l, r]`：叶子管单个元素，内部节点对半分给两个孩子，节点值 = 左右孩子合并
- 区间查询把目标区间拆成 `O(logn)` 个现成节点合并；单点更新同样只动一条链
- 懒标记 lazy：区间整体修改先记在节点上不下推，等真正访问孩子时再 pushDown —— 这是区间更新也是 `O(logn)` 的关键
- 选型：只要「加法前缀和」用树状数组（代码短）；要 min / max、区间改、更复杂的合并，用线段树

## 2. 数组表示

- 长度 4n 的数组按满二叉树编号：节点 i 的孩子是 `2i` 和 `2i + 1`
- 建树自底向上一次 `O(n)`；递归写法最直观，动态开点、非递归是进阶变体

## 3. 核心操作

| 操作                | 语义                                       | 复杂度    |
| ------------------- | ------------------------------------------ | --------- |
| build               | 建树                                       | `O(n)`    |
| addRange(l, r, v)   | 区间整体加（懒标记）                       | `O(logn)` |
| queryRange(l, r)    | 区间和                                     | `O(logn)` |
| `addRange(i, i, v)` | 用区间接口完成单点加，无独立 pointAdd 方法 | `O(logn)` |

本实现只支持“区间加 + 区间和”，不能只替换合并函数就得到任意区间更新。节点覆盖长度为 `len` 时，加 `v` 必须把 sum 增加 `v * len`，lazy 则累加 `v`；向下访问前，把这笔延迟增量分别传给两个孩子，再清空父标记。区间赋值等操作需要重新设计标记及其组合顺序。

构造输入必须非空，查询与更新使用从 0 开始的闭区间，建议满足 `0 <= l <= r < n`。源码没有空数组和参数校验；应用前应在调用边界保证条件。

## 4. 应用场景

| 场景                     | 要点                                    |
| ------------------------ | --------------------------------------- |
| 动态区间和 / 区间最值    | 带更新的 RMQ；静态 min/max 可考虑 ST 表 |
| 日程安排（区间冲突检测） | 预定前查区间 max，再区间加              |
| 扫描线求矩形面积并       | x 离散化 + 区间覆盖计数，按 x 排序推进  |
| 区间染色 / 覆盖长度统计  | 覆盖计数 + pushUp 维护有效长度          |
