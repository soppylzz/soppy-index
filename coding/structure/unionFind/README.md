# UnionFind（并查集）

> 管理不相交集合的合并与查询：find / union 均摊 `O(α(n))`（反阿克曼函数，可当常数），连通性问题的首选

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm unionFind
```

观察连通性、集合合并与连通分量计数。

## 1. 定义与性质

- 每个集合是一棵树，树根为集合的「代表元」；两个元素连通 <=> 同根
- union 把两棵树并成一棵，find 找元素所在树的根
- 两大优化，缺一不可：
  - 路径压缩：find 沿途节点直接挂到根上，树越用越扁
  - 按秩合并：矮树挂到高树下，避免退化成链
- 都用上时单次操作均摊 `O(α(n))`

## 2. 数组表示

- parent：`parent[i]` 指向父节点，初始 `parent[i] = i`（根指向自己）
- rank：树高上界，按秩合并的依据
- count：连通分量个数，每成功 union 一次减 1

## 3. 核心操作

| 操作      | 语义                           | 复杂度    |
| --------- | ------------------------------ | --------- |
| find      | 找代表元（带路径压缩）         | `O(α(n))` |
| union     | 合并两个集合，返回是否本就同根 | `O(α(n))` |
| connected | 判断是否连通                   | `O(α(n))` |
| count     | 连通分量个数                   | `O(1)`    |

## 4. 应用场景

| 场景                         | 要点                                     |
| ---------------------------- | ---------------------------------------- |
| 省份数量 / 朋友圈 / 连通分量 | 读入关系就 union，最后数 count           |
| 冗余连接（找多余边）         | 加边前两端已连通 => 这条边就是答案       |
| Kruskal 最小生成树           | 边按权排序，依次合并不连通的两端         |
| 等式方程 / 账户合并          | 先合并所有约束，再检查矛盾               |
| 带权并查集（除法求值）       | parent 额外存到父节点的权值，find 时累乘 |
