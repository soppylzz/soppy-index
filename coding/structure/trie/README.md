# Trie（字典树）

> 多叉前缀树：边存字符、节点存「是否成词」，插入 / 查找 / 前缀匹配都只跟词长有关 `O(L)`，与词库大小无关

[查看实现与示例](./index.ts)

在 `coding/structure/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm trie
```

对比完整单词查找、前缀匹配与前缀收集。

## 1. 定义与性质

- 一棵多叉树：根到某节点的路径上所有边字符连起来，就是该节点代表的前缀
- 公共前缀共享同一条路径 —— 词库的公共前缀只存一份
- isEnd 标记区分「只是别人的前缀」和「完整单词」
- 与哈希表的差异：哈希只能查完整 key，Trie 能按前缀查、按字典序遍历

## 2. 节点表示

- children：`Map<string, TrieNode>`；字符集固定且小（如小写字母）时可换成长度 26 的数组
- isEnd：boolean 标记
- 需要统计 / 删除时扩展计数：pass（经过次数）、end（成词次数），删除单词沿路径递减

## 3. 核心操作

| 操作       | 语义                   | 复杂度        |
| ---------- | ---------------------- | ------------- |
| insert     | 插入单词，沿途补建节点 | `O(L)`        |
| search     | 完整单词查找           | `O(L)`        |
| startsWith | 前缀匹配               | `O(L)`        |
| collect    | DFS 收集子树内所有成词 | `O(子树大小)` |

## 4. 应用场景

| 场景                          | 要点                                  |
| ----------------------------- | ------------------------------------- |
| 搜索框自动补全 / 联想         | startsWith 定位子树，DFS 收集候选词   |
| 单词搜索 II（矩阵中找单词）   | 词库建 Trie，走格子时沿 Trie 同步剪枝 |
| 01-Trie 求异或最值            | 按二进制位建树，每一位贪心走不同分支  |
| 敏感词过滤 / 路由最长前缀匹配 | AC 自动机 = Trie + 失配指针的进阶形态 |
