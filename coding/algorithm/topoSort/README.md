# TopoSort（拓扑排序）

> DAG 顶点的线性序：所有边都从左指向右。两大方法 —— Kahn（BFS 剥入度）与 DFS 逆后序，顺带完成判环

[查看实现与示例](./index.ts)

在 `coding/algorithm/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm topoSort
```

对比 Kahn 与 DFS 的拓扑序，并观察有环图的判定结果。

## 1. 定义与性质

- 只对 DAG 存在：有环则无拓扑序，所以排序过程天然就是判环
- 入度为 0 的点没有任何前置依赖，它们是当前可执行的全集
- 结果一般不唯一；Kahn 把队列换成小顶堆，可得到字典序最小的方案
- 两方法复杂度同为 `O(V + E)`：每个点处理一次、每条边看一次

以下用同一个图贯穿两个方法：边 `0->1, 0->2, 1->3, 2->3, 3->4`。

## 2. 方法一：Kahn（BFS 剥洋葱）

1. 统计所有点入度，入度 0 的点入队
2. 出队一个点追加到结果，把它指向的点入度减 1，减到 0 就入队
3. 队列空时：结果长度 = n 则合法，否则存在环

示例执行过程（初始入度：0:0，1:1，2:1，3:2，4:1）：

| 步  | 出队 | order           | 入度变化      | 队列   |
| --- | ---- | --------------- | ------------- | ------ |
| 1   | 0    | [0]             | 1 和 2 减到 0 | [1, 2] |
| 2   | 1    | [0, 1]          | 3: 2 -> 1     | [2]    |
| 3   | 2    | [0, 1, 2]       | 3: 1 -> 0     | [3]    |
| 4   | 3    | [0, 1, 2, 3]    | 4: 1 -> 0     | [4]    |
| 5   | 4    | [0, 1, 2, 3, 4] | ——            | []     |

- 判环：`A->B->C->A` 每个点入度 >= 1，队列始终为空，order 长度 0 < 3 => 有环
- 字典序最小变体：队列换小顶堆（见 [../../structure/heap/](../../structure/heap/)），其余不变
- 附赠信息：出队的「轮数」即 DAG 层数，可顺带求最长路 / 关键路径

## 3. 方法二：DFS 逆后序

- 对每个点 DFS，点完成（所有后继处理完）时压栈；最后弹栈序即拓扑序
- 正确性：u 指向 v，则 v 一定先于 u 完成，逆后序中 v 排在 u 前
- 环检测用三色标记：未访问 / 递归栈中 / 已完成，碰到「递归栈中」的点即有环

示例执行轨迹（从 0 发起 DFS，0 -> 1 -> 3 -> 4 一条路走到底再回溯）：

| 动作        | 后序 post       |
| ----------- | --------------- |
| dfs(4) 完成 | [4]             |
| dfs(3) 完成 | [4, 3]          |
| dfs(1) 完成 | [4, 3, 1]       |
| dfs(2) 完成 | [4, 3, 1, 2]    |
| dfs(0) 完成 | [4, 3, 1, 2, 0] |

逆后序 => `[0, 2, 1, 3, 4]`，与 Kahn 的 `[0, 1, 2, 3, 4]` 都是合法拓扑序 —— 再次说明结果不唯一

- 深图注意递归深度，工程上用显式栈改写

## 4. 方法对比

| 维度       | Kahn                   | DFS 逆后序             |
| ---------- | ---------------------- | ---------------------- |
| 实现方式   | 迭代 + 队列，无递归    | 递归（深图需显式栈）   |
| 判环方式   | 结果计数 < n           | 撞到「递归栈中」状态   |
| 字典序最小 | 队列换小顶堆即可       | 不方便                 |
| 附赠信息   | 逐层剥出，层数即最长路 | 无层次概念             |
| 适用       | 通用首选               | 图已给邻接表、顺手 DFS |
