# LCS（最长公共子序列）

> Longest Common Subsequence：两个序列公共子序列的最长者。两条路线 —— DP `O(mn)`，Myers `O((N+M)D)`（diff 的底层算法）

[查看实现与示例](./index.ts)

在 `coding/algorithm/` 子包内使用 Node >= 22.18 运行：

```bash
pnpm lcs
```

对比 DP 与 Myers 的长度结果，并观察公共子序列重建。

## 1. 定义与性质

- 子序列不要求连续；要求连续的版本叫「最长公共子串」，转移与答案统计位置都不同
- 最优子结构：两个前缀的 LCS 只取决于末尾字符能否配对 —— 典型重叠子问题
- 互补关系：只允许删除的编辑距离 = `m + n - 2 * LCS`（各自删到公共部分为止）

## 2. 方法一：动态规划 `O(mn)`

状态 `dp[i][j]` = s 前 i 个字符与 t 前 j 个字符的 LCS 长度。

末尾字符配对成功时收下这一对：

$$
dp[i][j] = dp[i-1][j-1] + 1,\quad s[i-1] = t[j-1]
$$

否则丢掉其中一个末尾字符，取较大者：

$$
dp[i][j] = \max(dp[i-1][j],\ dp[i][j-1])
$$

以 `s = "abcde"`、`t = "ace"` 为例的完整表：

|     | ""  | a   | c   | e   |
| --- | --- | --- | --- | --- |
| ""  | 0   | 0   | 0   | 0   |
| a   | 0   | 1   | 1   | 1   |
| b   | 0   | 1   | 1   | 1   |
| c   | 0   | 1   | 2   | 2   |
| d   | 0   | 1   | 2   | 2   |
| e   | 0   | 1   | 2   | 3   |

- 边界：`dp[0][j] = dp[i][0] = 0`（表中第一行、第一列）
- 空间优化：求长度只依赖上一行 + 左上角，滚动数组压到 `O(min(m, n))`（需暂存对角线旧值）；本例重建方案保留全表；Hirschberg 等分治算法可在较低空间重建，不属于当前实现
- 方案重建：从 `(m, n)` 回溯 —— 字符相等则收下并左上走，否则朝 dp 值更大的一侧走；上例收下 a、c、e

## 3. 方法二：Myers `O((N+M)D)`

换一个视角：LCS 的互补问题是「最短编辑脚本」SES —— 只用删除和插入把 a 变成 b 的最少步数 D，关系为 `LCS = (N + M - D) / 2`。Myers（1986，常用于文本 diff）在「编辑图」上按层找最小 D：

- 编辑图：x 轴方向走 a、y 轴方向走 b；右移 / 下移各记一次编辑，斜向匹配（`a[x] = b[y]`）免费
- 把编辑图按对角线 `k = x - y` 组织；`V[k]` 记录「用 d 次编辑在对角线 k 上能到达的最远 x」，到达后沿对角线贪心滑行（snake）
- 层间转移：`k = -d` 只能从 `k + 1` 下移，`k = d` 只能从 `k - 1` 右移，其余取两条相邻对角线中更远者；某层出现 `x >= N` 且 `y >= M` 即得 D
- 复杂度 通常写为 `O((N + M)D)`；计入 D=0 时仍需扫描匹配内容，可统一写为 `O((N+M)(D+1))`。两串越相似 D 越小，通常比 `O(mn)` 更有优势；最坏（完全不同）退化为 `O((N+M)^2)`
- 求 D 即得 LCS 长度；要具体编辑脚本需保存各层 V 回溯，或用线性空间的中点分治变体

以 `a = "abc"`、`b = "abd"` 为例（LCS = "ab"）：

| d   | k   | 到达方式                    | 起点   | snake 后          |
| --- | --- | --------------------------- | ------ | ----------------- |
| 0   | 0   | 起点                        | (0, 0) | 匹配 ab -> (2, 2) |
| 1   | -1  | 从 k=0 下移（b 的插入）     | (2, 3) | 越界              |
| 1   | 1   | 从 k=0 右移（a 的删除）     | (3, 2) | 越界              |
| 2   | -2  | 从 k=-1 下移                | (2, 4) | 越界              |
| 2   | 0   | 取 k=-1、k=1 中更远的 x = 3 | (3, 3) | 命中终点 => D = 2 |

`=> LCS = (3 + 3 - 2) / 2 = 2`

本例的滚动 DP 按第二个字符串分配 `O(n)` 空间；要得到 `O(min(m,n))`，还需先把较短串放到列方向。各实现按字符串下标比较 UTF-16 code unit，不按可见字素处理。

## 4. 方法对比

| 维度 | DP                    | Myers                          |
| ---- | --------------------- | ------------------------------ |
| 时间 | `O(mn)`，与内容无关   | `O((N+M)D)`，相似串快          |
| 空间 | 求长度 `O(min(m,n))`  | 求长度 `O(N+M)`                |
| 产物 | dp 表，可直接重建 LCS | 得 D；重建需保存各层或中点分治 |
| 适用 | 面试通用、短串        | 长文本、相似度高（diff 场景）  |
